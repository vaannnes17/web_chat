# Разработка WebSocket‑чата с использованием Express и Socket.IO.
## Часть 1 Разработка WebSocket‑чата
#### Изучить принципы работы WebSocket‑соединений, научиться использовать фреймворк Express и библиотеку Socket.IO для организации обмена сообщениями между клиентами.

### Задачи работы:
#### В проект лабораторной работы №8 подключить библиотеку Socket.IO 
#### Разработать интерфейс web-socket чата с использованием HTML/CSS/JS (или EJS‑шаблонов).
#### Реализовать выбранный функционал чата (см. варианты ниже).
#### Добавить механизм идентификации пользователей (имя или ID).
#### Обеспечить корректную обработку подключений и отключений пользователей.
#### На главную страницу проекта добавить ссылку на страницу с реализованным чатом. 
### Требования к реализации
#### Для WebSocket‑взаимодействия обязательно использовать Socket.IO.
#### Клиентская часть должна подключаться к серверу через Socket.IO‑клиент.
#### Предполагается использование EJS‑шаблонов для рендеринга страниц.

## Часть 2 Развёртывание приложения
#### Развернуть приложение на облачной платформе Render (см. руководство Деплой на Render.pdf).

### Задачи работы:
#### подготовить проект к деплою (PORT, npm start, структура проекта);
#### загрузить проект в GitHub;
#### создать Web Service на Render;
#### убедиться, что WebSocket‑функциональность работает в облаке.
